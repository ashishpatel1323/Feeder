Feeder · Feeds home, "By feed" as folder swimlanes (Android)

Each folder is a horizontal row of feed artwork with a clear header (name, feed count, unread). Tapping a header opens the folder; tapping artwork opens that feed. A, B and C are the three layouts. The last two screens show what happens when a folder has many feeds, and apply to A and B. Artwork here is placeholder colour; the real app uses each podcast/channel/site image, with a letter tile when there is none.
