Feeder · Feeds home, list view (Android)

Same folders and headers as option B, but feeds stacked one under another with their numbers. One icon button at the end of the chip row switches Tiles / List and is remembered. The list is for reading: tapping a row opens the feed, swipe start = Mark all read. Editing (rename, move, unsubscribe, full article) stays on Manage feeds, so rows have no ⋮.
