Recommended

A. Tabs under one header

One Books destination. M3 primary tabs Ebooks · Audiobooks · ZIM sit under a single top row. Swipe or tap to switch. Opens on the subtab you used last.

Top row (3 controls total)

  • Search ebooks pill: filters the current subtab in place. Label follows the subtab.
  • Dropbox cloud inside the pill: one account, so one icon for all three.
  • ⋮: Add, Check Dropbox, Cards / List, Sort.

Challenged

  • The full-width Cards | List row on every listing moves into ⋮. It's a set-once choice and costs ~48 dp above every shelf.
  • Refresh and Add (+) leave the top bar. Empty shelves still show Add chips.
  • Tabs, not a segmented switch: the three hold different content (M3 tabs). The Feeds switch stays segmented because Latest/By feed are views of the same items.
Android: Books › Ebooks (opened on last-used subtab)
Android: swiped to ZIM, ⋮ open

A on web

Sidebar loses three rows (Ebooks, Audiobooks, ZIM become Books). Page header = title, tabs, search, Dropbox button, ⋮. Same grid as PR #151.

Shortcuts

  • G B Books (last subtab)
  • G E / A / Z straight to Ebooks / Audiobooks / ZIM
  • [ ] previous / next subtab

URLs

  • #/books (last), #/books/ebooks, #/books/audiobooks, #/books/zim. Old #/audiobooks, #/zim links redirect; reader URLs don't change.
Web: Books › Audiobooks
Alternative

B. One shelf with type chips

No subtabs: a Continue row across all three types, then one shelf filtered by chips All · Ebooks · Audiobooks · ZIM.

Good

  • Pick up whatever you were last in, from one place.

Why not

  • Two chip rows: type chips and On phone / In Dropbox chips fight for the same space.
  • ZIM archives aren't books. Mixed in one grid, a 90 GB Wikipedia sits next to a novel and sorts oddly.
  • Add and Dropbox have to ask "which kind?" every time on All.
  • Breaks the three-subtab ask.

The Continue row is worth borrowing into A later.

Android: Books, All
Web: same, type chips in the header
Not recommended

C. Books home with shelves

Books opens on three swimlanes (like Feeds › By feed). See all opens today's full listing for that type.

Good

  • Overview of everything at a glance; reuses the existing listing screens unchanged.

Why not

  • Every real task (open a book, filter Dropbox, add) is one tap deeper, and Back has two levels.
  • Add / Dropbox / ⋮ either repeat per lane or need a hub menu.
  • "Remembered subtab" doesn't fit: you always land on the hub.

Web: same hub
